The flight software of the Apollo Guidance Computer used magnetic core-rope memory, meaning programmers of the day had to write their code on paper and type it into punch cards. This code was rigorously tested on giant mainframes. Once approved by NASA, the compiled binary data was sent to a Raytheon factory. There, factory workers physically wove copper wire through magnetic rings to create the hardware memory modules, literally weaving the software into existence.

In this simulator you can type a line of Apollo Guidance Computer assembly, and watch it get punched onto an 80‑column IBM card. Each punch card is 1 line of assembly, you can re-order the cards by changing their number (the rest of the deck shifts to make room). Then you can assemble the deck and run the code! Execution happens in order of the cards.

Quick Reference

This AGC-inspired simulator uses 4-bit opcodes and a 12-bit address-table ID, so it can switch banks automatically. Execution begins at START if present, otherwise at the first instruction. Reaching a word without an instruction finishes the program. TC Q returns from a subroutine. The arithmetic and INDEX behavior below is simplified for this simulator.
